1. Open a terminal in the project folder.

2. Paste this command, then press Enter.

   ```sh
   curl -fsSL https://your-server/setup.sh | sh -s -- your-repo --ci github
   ```

   </Path>

   <Path title="GitHub Actions, Windows" from="github" os="windows" level={4}>

   ```powershell
   & ([scriptblock]::Create((irm https://your-server/setup.ps1))) your-repo -Ci github
   ```

   </Path>

   <Path title="Jenkins with a Jenkinsfile, macOS or Linux" from="jenkins-pipeline" os="unix" level={4}>

   ```sh
   curl -fsSL https://your-server/setup.sh | sh -s -- your-repo --ci jenkins-pipeline
   ```

   </Path>

   <Path title="Jenkins with a Jenkinsfile, Windows" from="jenkins-pipeline" os="windows" level={4}>

   ```powershell
   & ([scriptblock]::Create((irm https://your-server/setup.ps1))) your-repo -Ci jenkins-pipeline
   ```

   </Path>

   <Path title="Jenkins freestyle job, macOS or Linux" from="jenkins-freestyle" os="unix" level={4}>

   ```sh
   curl -fsSL https://your-server/setup.sh | sh -s -- your-repo --ci jenkins-freestyle
   ```

   </Path>

   <Path title="Jenkins freestyle job, Windows" from="jenkins-freestyle" os="windows" level={4}>

   ```powershell
   & ([scriptblock]::Create((irm https://your-server/setup.ps1))) your-repo -Ci jenkins-freestyle
   ```

   </Path>

   The command finds Gradle or Maven in the folder and writes the files. It asks before it changes a file. You can run it again.

3. Commit the files it lists, and push them.

   ```sh
   git add .
   git commit -m "Publish to Telesphorepo"
   git push
   ```

   The files hold no secrets.

## Set up Jenkins

<Steps>

1. Install the Jenkins plugin **OpenID Connect Provider**.

   **Manage Jenkins** › **Plugins** › **Available plugins**

2. Open **Manage Jenkins** › **Credentials**, and add a credential.

3. Choose the kind **OpenID Connect id token**.

4. Fill in the **ID** and the **Audience**, then save.

   ```text
   ID         telesphorepo-id-token
   Audience   https://your-server
   ```

</Steps>

</Path>

<Path title="Jenkins with a Jenkinsfile: the job" from="jenkins-pipeline">

<Steps>

5. Make a Pipeline job that reads the `Jenkinsfile` from your repository.

6. Click **Build Now** on the job.

</Steps>

Done when the build log ends with `Finished: SUCCESS`.

</Path>

<Path title="Jenkins freestyle job: the job" from="jenkins-freestyle">

<Steps>

5. Open your job, then click **Configure**.

6. Under **Environment**, tick **Use secret text(s) or file(s)**.

7. Under **Bindings**, click **Add**, then **Secret text**.

8. Fill in the **Variable** and the **Credentials**.

   ```text
   Variable      OIDC_TOKEN
   Credentials   telesphorepo-id-token
   ```

9. Under **Build Steps**, click **Add build step**, then **Execute shell**.

10. Type the one line for your build tool.

    ```sh
    ./gradlew publish                                       # Gradle
    mvn -B deploy -Dtelesphorepo.oidcTokenEnv=OIDC_TOKEN    # Maven
    ```

11. Click **Save**, then **Build Now**.

</Steps>

Done when the build log ends with `Finished: SUCCESS`.

</Path>

## If something goes wrong

<details>
<summary>Find your problem, then do the fix</summary>

**The command does not find Gradle or Maven.** Run it in the folder that holds `settings.gradle`, `settings.gradle.kts` or `pom.xml`.

**The command cannot reach the server.** Check the address. Open it in a browser.

**The repository name is wrong.** Ask your server admin for the right name. Run the command again with it.

**Gradle says the `plugins` block is in the wrong place.** Move it to the top of the settings file. Only a `pluginManagement` block can come before it.

**GitHub Actions gave this job no identity token.** Add `id-token: write` under `permissions` in the workflow file.

**Jenkins gave this build no identity token.** Check the binding: the variable is `OIDC_TOKEN` and the credential is `telesphorepo-id-token`.

**The server refuses the job's token.** The **Audience** of the Jenkins credential must be the address of your server. Your server admin must also set the **Public address** on **Settings** › **General**.

**The token is too old.** The server takes a job's token for 10 minutes only. A freestyle job gets its token when the build starts. If the build takes longer, use a Jenkinsfile: it gets the token only for the publish stage.

**No CI pipeline matches the job.** Ask your server admin to check the values of the CI pipeline.

**The server cannot reach Jenkins.** Ask your server admin to paste the Jenkins keys into the CI pipeline. See [Run the server](/run-the-server/#add-a-ci-pipeline).

**The Jenkins agent runs Windows.** Choose **Execute Windows batch command** in place of **Execute shell**. In the line, write `gradlew.bat publish` for Gradle.

**Permission denied on `./gradlew` in CI.** Run `git update-index --chmod=+x gradlew`, then commit and push.

</details>

## Set it up by hand

<details>
<summary>The files for each build tool and each CI</summary>

Each file goes in the project folder. Commit each file to git. The files hold no secrets. Put your server's address in place of `https://your-server`, and your repository's name in place of `your-repo`.

### Gradle (Kotlin)

Paste this at the top of `settings.gradle.kts`. Only a `pluginManagement` block can come before it. If the file has a `plugins` block, add the `id` line to it.

```kotlin title="settings.gradle.kts"
plugins {
    id("com.telesphorepo.publish") version "0.1.0"
}

telesphorepo {
    url = "https://your-server"
    repository = "your-repo"
    oidcTokenEnv = "OIDC_TOKEN"
}
```

Give the project a group and a version in `build.gradle.kts`.

```kotlin title="build.gradle.kts"
group = "com.example"
version = "1.0.0"
```

### Gradle (Groovy)

Paste this at the top of `settings.gradle`. Only a `pluginManagement` block can come before it.

```groovy title="settings.gradle"
plugins {
    id 'com.telesphorepo.publish' version '0.1.0'
}

telesphorepo {
    url = 'https://your-server'
    repository = 'your-repo'
    oidcTokenEnv = 'OIDC_TOKEN'
}
```

Give the project a group and a version in `build.gradle`.

```groovy title="build.gradle"
group = 'com.example'
version = '1.0.0'
```

### Maven

Maven needs three files. All three go in the project folder, next to `pom.xml`, and not in `~/.m2`.

Create `.mvn/extensions.xml`.

```xml title=".mvn/extensions.xml"
<extensions>
  <extension>
    <groupId>com.telesphorepo</groupId>
    <artifactId>telesphorepo-maven-extension</artifactId>
    <version>0.1.0</version>
  </extension>
</extensions>
```

Create `.mvn/maven.config`.

```text title=".mvn/maven.config"
-Dtelesphorepo.url=https://your-server
```

Paste this into `pom.xml`, inside `<project>`.

```xml title="pom.xml"
<distributionManagement>
  <repository>
    <id>your-repo</id>
    <url>https://your-server/maven/your-repo</url>
  </repository>
  <snapshotRepository>
    <id>your-repo</id>
    <url>https://your-server/maven/your-repo</url>
  </snapshotRepository>
</distributionManagement>
```

### GitHub Actions

Create `.github/workflows/publish.yml`. For Maven, change the last line to `- run: mvn -B deploy`.

```yaml title=".github/workflows/publish.yml"
on:
  push:
    tags: ["v*"]

permissions:
  id-token: write
  contents: read

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-java@v6
        with:
          distribution: temurin
          java-version: 21
      - run: ./gradlew publish
```

### Jenkinsfile

Create `Jenkinsfile`. This one is for Gradle.

```groovy title="Jenkinsfile"
pipeline {
  agent any
  stages {
    stage('Build') {
      steps {
        sh './gradlew build'
      }
    }
    stage('Publish to your-repo') {
      steps {
        // The token is good for 10 minutes, so only this stage gets it.
        withCredentials([string(credentialsId: 'telesphorepo-id-token', variable: 'OIDC_TOKEN')]) {
          sh './gradlew publish'
        }
      }
    }
  }
}
```

For Maven, use these two `sh` lines in place of the Gradle lines.

```groovy title="Jenkinsfile"
sh 'mvn -B verify'
sh 'mvn -B deploy -DskipTests -Dtelesphorepo.oidcTokenEnv=OIDC_TOKEN'
```

### Jenkins freestyle job

A freestyle job needs no file. Choose **Jenkins freestyle job** at the top of the page to see its steps.

</details>
