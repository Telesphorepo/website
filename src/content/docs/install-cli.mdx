Install the CLI once on each computer that publishes. You install it from the server you publish to, so the CLI always matches that server.

The commands below use `https://repo.example.com`: put your server's address in its place. The web UI has the same lines with your address filled in. Open the account menu at the top right, then click **Install the CLI**.

<Place where="In a terminal" />

<Steps>

1. Run the install line. It downloads the CLI from your server, checks its SHA-256, and puts it in `~/.local/bin`.

   ```sh
   curl -fsSL https://repo.example.com/install.sh | sh
   ```

2. If the script asks `Add ~/.local/bin to your PATH in ~/.zshrc? [Y/n]`, press Enter. The name of the file follows your shell.

3. Open a new terminal, and check the install.

   ```sh
   telesphorepo version
   ```

</Steps>

<Place where="In PowerShell" />

<Steps>

1. Run the install line. It downloads the CLI from your server, checks its SHA-256, and adds its folder to your user PATH.

   ```powershell
   irm https://repo.example.com/install.ps1 | iex
   ```

2. Check the install in the same window.

   ```powershell
   telesphorepo version
   ```

</Steps>

## Related tasks

### Install in CI

The workflow files and the Jenkinsfile that the CLI writes install it already: see [Publish from CI](/publish-from-ci/). In a CI file of your own, add the install line as a step before `telesphorepo publish`. Outside GitHub Actions, also put the folder on the PATH:

```sh
curl -fsSL https://repo.example.com/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
telesphorepo publish
```

### Update the CLI

Run `telesphorepo update` after your server admin updates the server. When a server needs a newer CLI, the CLI asks `Update now?` on its own. Press Enter, and the CLI updates, then runs your command again.

```sh
telesphorepo update
```

### Download by hand

Open the account menu, then click **Install the CLI**. The page lists the archive for your system, its SHA-256, and the commands to check and install it. The archives and a `SHA256SUMS` file are also at `https://repo.example.com/cli/`.

## Troubleshooting

<details>
<summary>`telesphorepo` is not found in a new terminal</summary>

The folder of the CLI is not on your PATH. Run the install line again, and press Enter when the script asks about the PATH. The script asks only on a terminal: without one, it prints the line and the file to add it to, and you add that line yourself.

On Windows, open a new terminal. The install adds its folder to your user PATH, and only new terminals read it.

</details>

<details>
<summary>The script says that the SHA-256 differs</summary>

The download broke, and the script installed nothing. Run the line again. If it fails again, a proxy may cache an old file: ask your server admin.

</details>

<details>
<summary>The server has no CLI for your system, or no CLI downloads</summary>

The server has the CLI for Linux, macOS and Windows, on x86-64 and ARM. If the page says the server has no CLI downloads, ask your server admin to install a release, or a build made with `go tool task build`.

</details>

<details>
<summary>`telesphorepo update` cannot write the folder</summary>

Run the install line again, or fix the rights of the folder that the CLI names.

</details>

<details>
<summary>You lost a laptop</summary>

Open **Your account** › **Devices**, and revoke that laptop.

</details>
