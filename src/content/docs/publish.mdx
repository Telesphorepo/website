<Path title="Gradle" build="gradle">

<Steps>

1. Run the publish command.

   ```sh
   ./gradlew publish
   ```

2. The first time, click **Approve device** in the browser.

</Steps>

Done when Gradle prints `BUILD SUCCESSFUL`.

</Path>

<Path title="Maven" build="maven">

<Steps>

1. Run the publish command.

   ```sh
   mvn deploy
   ```

2. The first time, click **Approve device** in the browser.

</Steps>

Done when Maven prints `BUILD SUCCESS`.

</Path>

## If something goes wrong

<details>
<summary>Find your problem, then do the fix</summary>

**The browser page asks for two-step verification.** Click **Set up two-step verification**. Add your phone app, then approve.

**No browser page opens.** Copy the address that the terminal shows. Open it yourself.

**403 when you publish.** You cannot publish to this repository yet. Ask your server admin for **Publish**.

**409 when you publish.** That version is already on the server. Raise the version. You can publish a `-SNAPSHOT` version again and again.

**The server refused the device.** Delete the file that the message names. Publish again and approve again. An approval lasts 90 days, unless someone removes the device.

**You lost a laptop.** Open **Settings** › **Devices** and revoke that laptop.

**You want to approve the computer before you publish.** In the project folder, run `./gradlew telesphorepoLogin` or `mvn com.telesphorepo:telesphorepo-maven-plugin:login`.

**Gradle says `Task 'publish' not found`.** Add the `java` or `java-library` plugin to the build file.

**One project must not publish.** Add this line to the build file of that project:

```kotlin title="build.gradle.kts"
tasks.withType<PublishToMavenRepository>().configureEach { enabled = false }
```

**You publish without Gradle or Maven.** See [Debian, raw and curl](/debian-and-raw/).

</details>
