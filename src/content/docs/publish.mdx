The project folder holds `telesphorepo.toml`. One command publishes it, for Gradle and for Maven.

<Steps>

1. Install the Telesphorepo CLI once. Your server's address is the `server` line of `telesphorepo.toml`.

   ```sh
   curl -fsSL https://repo.example.com/install.sh | sh
   ```

   On Windows:

   ```powershell
   & ([scriptblock]::Create((irm https://repo.example.com/install.ps1)))
   ```

2. In the project folder, run the publish command.

   ```sh
   telesphorepo publish
   ```

3. The first time, the CLI prints a link and a code. Open the link, then click **Approve device**.

</Steps>

Done when Gradle prints `BUILD SUCCESSFUL`, or Maven prints `BUILD SUCCESS`.

The CLI runs `./gradlew publish` or `mvn deploy` for you, with your wrapper when the project has one. It prints the command before it runs it. It gives the build a publish token for this one repository, and ends the token when the build ends.

Project not set up yet? [Set up a project](/set-up/).

## If something goes wrong

<details>
<summary>Find your problem, then do the fix</summary>

**`no telesphorepo.toml in this folder or above`.** The project is not set up, or the file is not committed. [Set up a project](/set-up/), or pull the latest commit.

**The browser page asks for two-step verification.** Click **Set up two-step verification**. Add your phone app, then approve.

**No browser page opens.** Copy the address that the terminal shows. Open it yourself.

**403 when you publish.** You cannot publish to this repository yet. Ask your server admin for **Publish**.

**409 when you publish.** That version is already on the server. Raise the version. You can publish a `-SNAPSHOT` version again and again.

**The server refused the device.** Run `telesphorepo login` with your server's address, and approve again. An approval lasts 90 days, unless someone removes the device.

**The CLI says that it needs a newer CLI.** Answer `Y` to update, or run `telesphorepo update`. The CLI then runs the command again.

**The CLI says that it needs a newer server.** Ask your server admin to update the server.

**You lost a laptop.** Open **Settings** › **Devices** and revoke that laptop.

**You want to approve the computer before you publish.** Run `telesphorepo login https://repo.example.com`.

**You want to see what the CLI will run.** Run `telesphorepo status` in the project folder.

**Gradle says that no project applies `maven-publish`.** Add the `maven-publish` plugin to the build file of each project to publish.

**One project must not publish.** Add this line to the build file of that project:

```kotlin title="build.gradle.kts"
tasks.withType<PublishToMavenRepository>().configureEach { enabled = false }
```

**You publish a Debian package or a plain file.** See [Debian, raw and curl](/debian-and-raw/).

</details>
