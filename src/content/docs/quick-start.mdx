Run Telesphorepo on your own computer, make a repository and publish a package to it. It takes Docker and a project to publish: Maven, Gradle, npm, Python, Cargo or .NET.

## Start the server

<Path title="macOS or Linux" os="unix" level={3}>

<Place where="In a terminal" />

<Steps>

1. Start the server. Docker keeps its data in the volume `telesphorepo-data`, and its daily backups in `telesphorepo-backups`.

   ```sh
   docker run -d --name telesphorepo -p 8080:8080 \
     -v telesphorepo-data:/data -v telesphorepo-backups:/backups \
     ghcr.io/telesphorepo/telesphorepo:latest
   ```

2. Print the log of the server. On its first start, the server writes a box titled "First start: created admin user" with a "password:" line in it. Copy that password: the server shows it only once.

   ```sh
   docker logs telesphorepo
   ```

</Steps>

</Path>

<Path title="Windows" os="windows" level={3}>

<Place where="In PowerShell, with Docker Desktop running" />

<Steps>

1. Start the server. Docker keeps its data in the volume `telesphorepo-data`, and its daily backups in `telesphorepo-backups`.

   ```powershell
   docker run -d --name telesphorepo -p 8080:8080 `
     -v telesphorepo-data:/data -v telesphorepo-backups:/backups `
     ghcr.io/telesphorepo/telesphorepo:latest
   ```

2. Print the log of the server. On its first start, the server writes a box titled "First start: created admin user" with a "password:" line in it. Copy that password: the server shows it only once.

   ```powershell

   ```

</Steps>

</Path>

<Done>Done when you have the password of the user `admin`.</Done>

## Sign in

<Place where="In a browser, at http://localhost:8080" />

<Steps>

1. Open `http://localhost:8080`, and sign in as `admin` with the password from the log.

2. The page asks for a second step before you go on. Under **Authenticator app**, click **Add**. Type a name, such as `Phone`, and click **Continue**.

3. Scan the code with the app on your phone, type the 6-digit code in **Code from the app**, and click **Add app**.

</Steps>

<Done>Done when the page says **Two-step verification is on**.</Done>

## Make a repository

<Place where="In Telesphorepo" />

<Steps>

1. Open **Settings** › **Repositories**, and click **New repository**.

2. Choose **A repository**.

3. Type a name, such as `releases`.

4. Choose the format of your project, such as **Maven / Gradle**.

5. Under **Who can download**, choose **Private**.

6. Click **Create repository**.

</Steps>

<Done>Done when the new repository opens on its **Use this repository** tab.</Done>

## Publish

<Place where="In Telesphorepo, on the page of the repository" />

<Steps>

1. Click the **Publish to this repository** tab, then **Set up a project**, and confirm with your second step. The page shows a setup line: one command that installs the Telesphorepo CLI and sets up the project. It shows the line for the system of your browser, and a switch for the other.

</Steps>

<Path title="macOS or Linux" os="unix" level={3}>

<Place where="In a terminal, in the project folder" />

<Steps>

2. Copy the setup line, paste it into the terminal, and press Enter. The line installs the CLI, approves this computer, and writes `telesphorepo.toml` into the folder. If it asks to add `~/.local/bin` to your PATH, press Enter.

3. The CLI asks "Add a CI file that publishes to releases?" and numbers four answers. Press Enter to take "1) No CI file". [Publish from CI](/publish-from-ci/) adds one later.

4. Publish the project. The CLI runs the publish command of your build tool, such as `mvn deploy` or `npm publish`. If the terminal answers "telesphorepo: command not found", open
 a new terminal in the project folder and run it there.

   ```sh
   telesphorepo publish
   ```

</Steps>

</Path>

<Path title="Windows" os="windows" level={3}>

<Place where="In PowerShell, in the project folder" />

<Steps>

2. Copy the setup line, paste it into PowerShell, and press Enter. The line installs the CLI, approves this computer, and writes `telesphorepo.toml` into the folder.

3. The CLI asks "Add a CI file that publishes to releases?" and numbers four answers. Press Enter to take "1) No CI file". [Publish from CI](/publish-from-ci/) adds one later.

4. Publish the project in the same window. The CLI runs the publish command of your build tool, such as `mvn deploy` or `npm publish`.

   ```powershell
   telesphorepo publish
   ```

</Steps>

</Path>

<Done>Done when the **Files** tab of the repository shows your package.</Done>
