Every Maven repository has one address: `https://repo.example.com/maven/<name>`. Gradle and Maven read from it like from any Maven repository.

The repository page in the web UI shows these snippets with your address filled in. Open the repository, then click **Use this repository**.

## Public repository

Anyone can download from a public repository. Add the repository to your build:

<Tabs syncKey="build">
<TabItem label="Gradle (Kotlin)">

```kotlin title="build.gradle.kts"
repositories {
    maven {
        name = "releases"
        url = uri("https://repo.example.com/maven/releases")
    }
    mavenCentral()
}

dependencies {
    implementation("com.example:my-lib:1.0.0")
}
```

</TabItem>
<TabItem label="Gradle (Groovy)">

```groovy title="build.gradle"
repositories {
    maven {
        name = 'releases'
        url = 'https://repo.example.com/maven/releases'
    }
    mavenCentral()
}

dependencies {
    implementation 'com.example:my-lib:1.0.0'
}
```

</TabItem>
<TabItem label="Maven">

```xml title="pom.xml"
<repositories>
  <repository>
    <id>releases</id>
    <url>https://repo.example.com/maven/releases</url>
  </repository>
</repositories>

<dependencies>
  <dependency>
    <groupId>com.example</groupId>
    <artifactId>my-lib</artifactId>
    <version>1.0.0</version>
  </dependency>
</dependencies>
```

</TabItem>
</Tabs>

Replace `com.example:my-lib:1.0.0` with the dependency that you need. Then build as usual.

## Private repository

A private repository needs your username and a read token. A read token can download. It cannot publish.

<Steps>

1. Create a read token. In the web UI, open **Settings**, then **Tokens**. Click **New read token**, enter a name, and click **Create token**. Copy the token. The page shows it once.

2. Put the token where your build tool reads it.

   <Tabs syncKey="build">
   <TabItem label="Gradle (Kotlin)">

   ```properties title="~/.gradle/gradle.properties"
   releasesUsername=YOUR_USERNAME
   releasesPassword=YOUR_READ_TOKEN
   ```

   </TabItem>
   <TabItem label="Gradle (Groovy)">

   ```properties title="~/.gradle/gradle.properties"
   releasesUsername=YOUR_USERNAME
   releasesPassword=YOUR_READ_TOKEN
   ```

   </TabItem>
   <TabItem label="Maven">

   ```xml title="~/.m2/settings.xml"
   <settings>
     <servers>
       <server>
         <id>releases</id>
         <username>YOUR_USERNAME</username>
         <password>YOUR_READ_TOKEN</password>
       </server>
     </servers>
   </settings>
   ```

   If the file already has a `<servers>` element, add only the `<server>` element to it.

   </TabItem>
   </Tabs>

3. Add the repository to your build.

   <Tabs syncKey="build">
   <TabItem label="Gradle (Kotlin)">

   ```kotlin title="build.gradle.kts"
   repositories {
       maven {
           name = "releases"
           url = uri("https://repo.example.com/maven/releases")
           credentials(PasswordCredentials::class)
       }
       mavenCentral()
   }
   ```

   Gradle reads `releasesUsername` and `releasesPassword` because the repository has the name `releases`.

   </TabItem>
   <TabItem label="Gradle (Groovy)">

   ```groovy title="build.gradle"
   repositories {
       maven {
           name = 'releases'
           url = 'https://repo.example.com/maven/releases'
           credentials(PasswordCredentials)
       }
       mavenCentral()
   }
   ```

   Gradle reads `releasesUsername` and `releasesPassword` because the repository has the name `releases`.

   </TabItem>
   <TabItem label="Maven">

   ```xml title="pom.xml"
   <repositories>
     <repository>
       <id>releases</id>
       <url>https://repo.example.com/maven/releases</url>
     </repository>
   </repositories>
   ```

   Maven sends the `<server>` whose `<id>` is the same as the `<id>` of the repository.

   </TabItem>
   </Tabs>

</Steps>

<details>
<summary>Read a private repository in CI</summary>

Keep the token in a CI secret. Then pass it as environment variables:

<Tabs syncKey="build">
<TabItem label="Gradle (Kotlin)">

```sh
export ORG_GRADLE_PROJECT_releasesUsername=YOUR_USERNAME
export ORG_GRADLE_PROJECT_releasesPassword=YOUR_READ_TOKEN
```

</TabItem>
<TabItem label="Gradle (Groovy)">

```sh
export ORG_GRADLE_PROJECT_releasesUsername=YOUR_USERNAME
export ORG_GRADLE_PROJECT_releasesPassword=YOUR_READ_TOKEN
```

</TabItem>
<TabItem label="Maven">

```xml title="~/.m2/settings.xml"
<server>
  <id>releases</id>
  <username>${env.REPO_USERNAME}</username>
  <password>${env.REPO_TOKEN}</password>
</server>
```

Set `REPO_USERNAME` and `REPO_TOKEN` in the CI job.

</TabItem>
</Tabs>

</details>

<details>
<summary>Use Gradle plugins from the repository</summary>

Add the repository to `pluginManagement` at the top of the settings file:

<Tabs syncKey="build">
<TabItem label="Gradle (Kotlin)">

```kotlin title="settings.gradle.kts"
pluginManagement {
    repositories {
        maven {
            name = "releases"
            url = uri("https://repo.example.com/maven/releases")
        }
        gradlePluginPortal()
    }
}
```

</TabItem>
<TabItem label="Gradle (Groovy)">

```groovy title="settings.gradle"
pluginManagement {
    repositories {
        maven {
            name = 'releases'
            url = 'https://repo.example.com/maven/releases'
        }
        gradlePluginPortal()
    }
}
```

</TabItem>
<TabItem label="Maven">

Maven reads plugins from `<pluginRepositories>` in `pom.xml`. Use the same `<id>` and `<url>` as above.

</TabItem>
</Tabs>

For a private repository, add the `credentials` line from step 3.

</details>

<Aside type="caution">
Maven 3.8.1 and later refuse `http://` repositories on any host except localhost. Serve the server over HTTPS. See [Run in production](/production/).
</Aside>
