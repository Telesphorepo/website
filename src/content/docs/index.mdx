## No password can publish

A password or a read token can only download. Each publish gets its own token for one repository, and the token ends within 15 minutes.

One command, `telesphorepo publish`, gets the token for Gradle, Maven, npm, Python, Cargo, .NET, Helm, Debian and raw files, on your computer and in CI. Docker gets it from the same CLI.
