## One command to publish

Run `telesphorepo publish`, and the CLI runs the publish command of your own build tool: `mvn deploy`, `npm publish`, `cargo publish`, `dotnet pack`, `helm push`. You set the project up once, with one line from the web UI. You add no repository address and no password to the build.

Run the same command in GitHub Actions and in Jenkins. Push Docker images with no `docker login`.

## Only the features you actually want

Other artifact servers have every feature, and then cost tens of thousands a year or make every task a chore. Telesphorepo keeps the ones worth having, and stays easy to use.

<ul class="tr-features not-content">
<li><a href="/use-packages/"><strong>Every repository explains itself</strong><span>Open a repository and copy the setup for your tool, with your address filled in: Maven, Gradle, npm, pip, Cargo, apt, dnf, Docker.</span></a></li>
<li><a href="/repositories-and-access/#add-public-packages"><strong>Proxies and groups</strong><span>Keep a copy of what your builds download from Maven Central, npm or PyPI. Serve it with your own packages from one address.</span></a></li>
<li><a href="/publish-from-ci/"><strong>CI with no stored secret</strong><span>A GitHub Actions or Jenkins job publishes as itself. There is no key to store and none to rotate.</span></a></li>
<li><a href="/move-from-nexus/"><strong>A way out of Nexus</strong><span>Add your Nexus 3 server. Telesphorepo copies its repositories and keeps them in sync until you switch over.</span></a></li>
<li><div><strong>Search that stays fast</strong><span>A search takes the same time with a million files as with a hundred thousand.</span></div></li>
<li><a href="https://github.com/Telesphorepo/Telesphorepo/tree/main/edge"><strong>Downloads from a nearby region</strong><span>With Cloudflare R2, people far from the server download from a bucket near them.</span></a></li>
<li><a href="/back-up-and-restore/"><strong>Backups built in</strong><span>The server writes a backup every day and keeps the last seven. One command restores one.</span></a></li>
<li><a href="/people-and-sign-in/"><strong>The sign-in your company has</strong><span>Single sign-on with any OpenID Connect provider, passkeys, permissions for each repository, and an audit log.</span></a></li>
</ul>

## Free, and yours to run

The server is open source under AGPL-3.0, and the CLI under MIT. There are no seats, no tiers and no sales call. It runs on your machine, and your packages stay yours.
