## Every publish gets its own ticket

No long-lived password can upload. Each publish gets a token for one repo that ends after 15 minutes.

The Gradle plugin, the Maven extension and CI do this for you on every publish.

</div>

## As fast at a million files as at a hundred thousand

Every request uses an index, so a large repo answers as fast as a small one. The scale test checks this on every run.

<ScaleTest />

## One image. Nothing else to run.

There is no database server and no search cluster. The whole install is three things.

<Install />

Binaries for Linux, macOS and Windows are on [GitHub Releases](https://github.com/Telesphorepo/Telesphorepo/releases). The [install guide](/getting-started/install/) has every way to run it.
